# Task Manager — QA Portfolio Project

## 👤 О проекте

Веб-приложение для управления задачами. Создано как проект для портфолио QA-специалиста с полным циклом тестирования.

**🔗 Live Demo:** https://dazzling-hamster-1eccf4.netlify.app/

---

## 📋 Функциональные требования

✅ Добавление новой задачи  
✅ Удаление задачи  
✅ Редактирование задачи  
✅ Отметка задачи как выполненной/невыполненной  
✅ Фильтрация задач (Все / Активные / Выполненные)  
✅ Сохранение данных после перезагрузки (localStorage)  
✅ Адаптивный дизайн (мобильная версия)  
✅ Тёмная тема в стиле терминала  

---

## 🛠 Технологический стек

**Frontend:** React + Vite  
**Хранение данных:** localStorage  
**Стили:** CSS (адаптивный дизайн)  
**Деплой:** Netlify  
**Version Control:** Git + GitHub

## 📁 Структура QA-документации

Вся тестовая документация находится в папке [`qa-docs/`](qa-docs):

### 📌 [`checklist.md`](qa-docs/checklist.md)
Чек-лист тестирования приложения по категориям:
- Функциональное тестирование
- Сохранение данных
- UI/UX тестирование
- Адаптивность
- Кросс-браузерное тестирование
- Граничные случаи

### 📝 [`test-cases.md`](qa-docs/test-cases.md)
5 подробных тест-кейсов с:
- ID и приоритетом
- Предусловиями
- Пошаговыми инструкциями
- Ожидаемыми результатами
- Статусами выполнения

### 🐛 [`bug-reports.md`](qa-docs/bug-reports.md)
3 баг-репорта с:
- Окружением тестирования
- Шагами воспроизведения
- Скриншотами
- Статусами (все баги не подтвердились — приложение качественное!)

### 📸 [`screenshots/`](qa-docs/screenshots)
Скриншоты, подтверждающие результаты тестирования

## 🚀 Как запустить локально

```bash
# Клонировать репозиторий
git clone https://github.com/annasamolina/task-manager-qa.git

# Перейти в папку проекта
cd task-manager-qa

# Установить зависимости
yarn install

# Запустить в режиме разработки
yarn dev
