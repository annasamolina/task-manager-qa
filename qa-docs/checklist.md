# Чек-лист тестирования Task Manager

## 1. Функциональное тестирование

### Добавление задачи
- [ ] Добавить задачу с текстом
- [ ] Добавить пустую задачу (должна быть валидация)
- [ ] Добавить задачу с пробелами только
- [ ] Добавить задачу нажатием Enter
- [ ] Добавить задачу нажатием кнопки "Добавить"
- [ ] Поле ввода очищается после добавления

### Удаление задачи
- [ ] Удалить задачу кнопкой "Del"
- [ ] Удалить выполненную задачу
- [ ] Удалить единственную задачу

### Редактирование задачи
- [ ] Нажать кнопку "Edit" — появляется поле ввода
- [ ] Изменить текст задачи
- [ ] Сохранить изменения кнопкой "OK"
- [ ] Отменить изменения кнопкой "Отмена"
- [ ] Сохранить изменения нажатием Enter
- [ ] Попытаться сохранить пустой текст

### Статус задачи
- [ ] Отметить задачу как выполненную (чекбокс)
- [ ] Снять отметку с выполненной задачи
- [ ] Визуальное отличие выполненных задач (зачёркивание, цвет)

### Фильтрация
- [ ] Фильтр "Все" показывает все задачи
- [ ] Фильтр "Активные" показывает только невыполненные
- [ ] Фильтр "Выполненные" показывает только выполненные
- [ ] Переключение между фильтрами работает корректно
- [ ] Активный фильтр визуально выделен

## 2. Сохранение данных

- [ ] Задачи сохраняются после перезагрузки страницы
- [ ] Статусы задач сохраняются после перезагрузки
- [ ] Фильтр сбрасывается на "Все" после перезагрузки
- [ ] Данные сохраняются в localStorage

## 3. UI/UX тестирование

- [ ] Все элементы отображаются корректно
- [ ] Шрифт Fira Code применяется ко всем элементам
- [ ] Тёмная тема работает корректно
- [ ] Фото Пикселя отображается
- [ ] Кнопки имеют hover-эффекты
- [ ] Placeholder в поле ввода отображается

## 4. Адаптивность

- [ ] Интерфейс корректно отображается на мобильных устройствах
- [ ] Кнопки действий переносятся под текст задачи на мобильных
- [ ] Фильтры переносятся на новую строку при нехватке места
- [ ] Отступы уменьшаются на мобильных устройствах

- [ ] Safari
- [ ] Firefox
- [ ] Edge

## 6. Граничные случаи

- [ ] Добавить задачу с максимальным количеством символов
- [ ] Добавить задачу со специальными символами
- [ ] Добавить задачу с эмодзи
- [ ] Быстрое добавление множества задач
- [ ] Удаление всех задач
