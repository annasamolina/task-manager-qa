## TC-001: Добавление задачи с валидным текстом

**Приоритет:** High  
**Модуль:** Добавление задачи  
**Автор:** Anna Samolina  
**Дата создания:** 11.06.2026

### Предусловия
- Приложение открыто в браузере
- Список задач пуст или содержит задачи

### Шаги выполнения
1. Кликнуть на поле ввода "Введите задачу..."
2. Ввести текст: "Купить корм для Пикселя"
3. Нажать кнопку "[Добавить]"

### Ожидаемый результат
- Задача "Купить корм для Пикселя" появляется в списке
- Поле ввода очищается
- Задача имеет статус "не выполнена" (чекбокс не отмечен)
- Задача отображается с белым фоном (не зелёным)

### Фактический результат
_Заполнить после выполнения_

### Статус

**Модуль:** Статус задачи  
**Автор:** Anna Samolina  
**Дата создания:** 11.06.2026

### Предусловия
- В списке есть хотя бы одна задача
- Задача имеет статус "не выполнена"

### Шаги выполнения

- Текст задачи зачёркивается

## TC-005: Сохранение данных после перезагрузки страницы

**Приоритет:** High  
**Модуль:** Сохранение данных  
**Автор:** Anna Samolina  
**Дата создания:** 11.06.2026

### Предусловия
- В списке есть минимум 1 задача
- Задача имеет любой статус (выполнена или нет)

### Шаги выполнения
1. Добавить задачу (если список пуст)
2. Нажать F5 или Cmd+R для перезагрузки страницы
3. Дождаться полной загрузки приложения

### Ожидаемый результат
- Задача остаётся в списке после перезагрузки
- Статус задачи (выполнена/не выполнена) сохранён
- Текст задачи не изменился

### Фактический результат
_Заполнить после выполнения_

### Статус
⬜ Pass /  Fail / ⬜ Not Tested
