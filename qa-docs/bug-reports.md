# Баг-репорты Task Manager

## BUG-001: Добавление задачи с пробелами

**Статус:** Open  
**Приоритет:** Medium  
**Серьёзность:** Minor  
**Окружение:**  
- OS: macOS  
- Browser: Chrome 120  
- URL: https://dazzling-hamster-1eccf4.netlify.app/

### Описание
Приложение позволяет добавить задачу, состоящую только из пробелов.

### Шаги воспроизведения
1. Открыть приложение
2. В поле ввода ввести только пробелы (например, "   ")
3. Нажать кнопку "[Добавить]"

### Ожидаемый результат
Задача НЕ добавляется, так как не содержит видимого текста. Поле ввода остаётся пустым.

### Фактический результат
Задача добавляется в список с пустым текстом. Отображается пустая строка в списке задач.

### Вложения
_Скриншот можно добавить позже_

## BUG-002: Редактирование задачи на пустой текст

**Статус:** Open  
**Приоритет:** High  
**Серьёзность:** Major  
**Окружение:**  
- OS: macOS  
- Browser: Chrome 120  
- URL: https://dazzling-hamster-1eccf4.netlify.app/

### Описание
При редактировании задачи можно сохранить пустой текст, что приводит к отображению пустой задачи в списке.

### Шаги воспроизведения
1. Добавить задачу с текстом "Тестовая задача"
2. Нажать кнопку "[Edit]" рядом с задачей
3. Удалить весь текст из поля ввода
4. Нажать кнопку "[OK]"

### Ожидаемый результат
Изменения НЕ сохраняются. Задача остаётся с исходным текстом "Тестовая задача". Либо появляется сообщение об ошибке.

### Фактический результат
Задача сохраняется с пустым текстом. В списке отображается пустая строка.

### Вложения
_Скриншот можно добавить позже_

## BUG-003: Отсутствие валидации специальных символов

**Статус:** Open  
**Приоритет:** Low  
**Серьёзность:** Minor  
**Окружение:**  
- OS: macOS  
- Browser: Chrome 120  
- URL: https://dazzling-hamster-1eccf4.netlify.app/

### Описание
Приложение не валидирует ввод специальных символов и HTML-тегов в поле задачи.

### Шаги воспроизведения
1. Открыть приложение
2. В поле ввода ввести: `<script>alert('XSS')</script>`
3. Нажать кнопку "[Добавить]"

### Ожидаемый результат
Специальные символы экранируются и отображаются как обычный текст.

### Фактический результат
_Заполнить после тестирования_

### Вложения
_Скриншот можно добавить позже_
